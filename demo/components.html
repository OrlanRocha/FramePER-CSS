Framework completo de gráficos incorporado ao Frame PER sem nenhuma dependência externa. Suporta múltiplos modelos com inicialização declarativa (data-chart) ou via API JavaScript (new FramePER.Chart). Ver demonstração completa com todos os 9 modelos →

Gráfico de Rosca (Donut) 
<!-- Inicialização via HTML -->
<div class="frame-chart" data-chart="area" data-chart-data='{"labels":["Jan",...],"series":[{"name":"Receita","data":[15000,...]}]}'></div>

<!-- Ou via JavaScript -->
const chart = new FramePER.Chart('#meu-grafico', {
  type: 'donut',
  data: { series: [{ name: 'A', value: 60 }, { name: 'B', value: 40 }] }
});
