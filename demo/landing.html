Simplicidade de Uso

Desenvolva com produtividade e clareza

Importe os bundles compilados e tenha um ecossistema completo de componentes e utilitários à disposição instantaneamente.

  • Sem necessidade de bundlers complexos como Webpack ou Vite se não quiser.
  • API limpa exposta globalmente via window.FramePER.
  • Modais, Offcanvas e Dropdowns ativados via atributos HTML simples.
<!-- Importação direta no HTML -->
<link rel="stylesheet" href="dist/framePER.min.css">
<script src="dist/framePER.min.js"></script>

<!-- Exemplo de Requisição HTTP com Loader Automático -->
<script>
  async function carregarDados() {
    FramePER.Loader.showPageLoad();
    const res = await FramePER.Http.get('/api/dash');
    FramePER.Loader.hidePageLoad();

    if (res.ok) {
      FramePER.Notify.success('Sucesso', 'Dados atualizados!');
    }
  }
</script>
